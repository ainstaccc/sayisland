# 說說島｜每晚新增題目作業說明（給自動排程的 Claude 看）

目標：每天凌晨為 6 個關卡各新增 10 題（量詞 Q、動詞 V、形容詞 A、因果配對 M、短文小偵探 E、好好說話 H），全部寫入 `bank.js`，驗證通過後推上 main。

## 每個關卡的 10 題怎麼分配
- 3 個難度（1＝低年級 1–2 年級，2＝中年級 3–4 年級，3＝高年級 5–6 年級）輪流多一題：10 題 ＝ 3＋3＋4，哪個難度拿 4 題依「今天日期 ÷ 3 的餘數」輪替（餘 0→難度1、餘 1→難度2、餘 2→難度3）。
- 看圖說話、注音拼音不在這個作業範圍。

## 步驟
1. `git clone https://github.com/ainstaccc/sayisland && cd sayisland`（若已存在就 `git pull`）。
2. 先讀 `index.html` 內該關卡既有題目（搜尋 `const Q1=[`、`const V1=[`、`const A1=[`、`const M1=[`、`const E1=[`、`const H1=[`）與 `bank.js`，了解格式、難度、語氣，並避免寫出重複或幾乎相同的題。
3. 產生新題，存成暫存檔 `/tmp/new.json`，格式：`{"Q1":[[...],...],"Q2":[...],"E1":[{...}],"H2":[[...]]}`（key＝關卡字母＋難度數字）。各格式照既有題一模一樣：
   - **Q 量詞／V 動詞／A 形容詞**：`[emoji, "含一個＿＿的句子", 正確答案, 錯誤1, 錯誤2, 一句提示]`。選項 ≤4 字。錯誤選項必須「明確不對」，不能有第二個合理答案。
   - **M 因果配對**：`[emoji, 原因(≤7字), 結果(≤8字)]`。原因和結果要有明確因果，且不能套到別題的結果。
   - **E 短文小偵探**：物件 `{e,noun,scene,parts:[[類型,'b或a','問題',正解,錯1,錯2],...]}`；類型只用 數量/樣子/地點/動作/心情/原因；3～4 個問題；數量題的問題固定寫「有幾個？」。正解必須能在短文中直接找到。
   - **H 好好說話**：`[emoji, 情境, 誰在說, 最好的說法, 較差說法1, 較差說法2, 小提醒, 為什麼1(較差1不好的原因), 為什麼2]`。三種說法講同一件事；較差的說法要是真實孩子會說的話，不可使用髒話、人身攻擊的重話或歧視字眼；語氣溫和、不說教。
4. 內容品質守則（最重要）：
   - 用字、句長、生活經驗要符合該年級；用台灣國語詞彙與繁體字；用台灣常用量詞、說法。
   - 不碰暴力、恐怖、政治、宗教、廣告、品牌、真人姓名。
   - 每題只有一個正解；答案不能從句子文法直接猜出（例如選項只有一個符合量詞的語感）。
   - 有破音字的詞，答案或選項盡量避開；非用不可時沒關係（App 有發音修正）。
5. `node tools/add.js /tmp/new.json`：會驗證、擋掉重複，並印出各關卡實際新增數。若某關卡新增數 < 10，補寫該關卡的題再跑一次（每個 key 重複題會被擋掉，不會重複寫入）。
6. `node tools/check.js`：必須印出 `ALL OK`。失敗就修正 `bank.js`（只能刪新加的題，絕對不要改 `index.html` 原有題目順序，也不要刪舊題，題目編號依順序，改了孩子進度會對不上）。
7. 驗證 App 能開：用 Playwright 載入 `file://.../index.html`（注入 `[hidden]{display:none!important}`），輸入暱稱進入首頁，確認沒有 `pageerror`、並進入任一關卡能出題。失敗就還原 `bank.js`（`git checkout bank.js`），不要推上去。
8. 在 `tools/nightly-log.md` 最上面追加一行：日期、各關卡新增數、新總數。
9. `git add -A && git commit && git push origin main`。commit 訊息：`nightly: 新增題目 YYYY-MM-DD`，結尾加上排程給的 Co-Authored-By 與 Claude-Session 行。
10. 最後回報：各關卡新增數、有無被擋掉的題、push 是否成功。

## 絕對不要做
- 不要改 `index.html` 的程式或既有題庫（只能改 `bank.js`、`tools/nightly-log.md`）。
- 不要刪除或重排既有題目。
- 驗證沒過就不要 push。
- 不要把 firebase 設定、金鑰以外的任何個資寫進檔案。
