# 說說島｜使用手冊（v1.1.3 原型）


## 0. 網址與安裝（GitHub Pages 版）
- 網址：`https://ainstaccc.github.io/sayisland/`（repo 的 Settings → Pages，Branch `main`、`/ (root)`）。
- iPhone：用 Safari 開網址 → 分享 → 加入主畫面 →「打開為網頁 App」。因為是獨立網址，進度存在這個網址自己的儲存區，不再受 claude.ai 嵌入頁影響。
- 檔案：`index.html`（整個 App）、`manifest.json`、`icon-*.png`、本 README。更新 App 時只要覆蓋 `index.html`。
- 進度不會因為改版消失（只新增欄位）；仍建議偶爾在首頁按「複製存檔碼」備份。
給小學低、中、高年級的「詞語＋句子＋表達」闖關遊戲。目前是單一 HTML 檔，手機瀏覽器直接開，用來讓小朋友和家長試玩，驗證好不好玩。

## 1. 快速開始檢查表

## 2. 六個關卡
| 關卡 | 玩法 | 練什麼 |
|---|---|---|
| 量詞 | 三選一，填「一＿書」 | 量詞 |
| 動詞 | 三選一，選最貼切的動作 | 動詞 |
| 形容詞 | 三選一，選樣子、味道 | 形容詞 |
| 短文小偵探（原「擴句」） | 讀一段短文，再回答「有幾個？什麼樣子？在哪裡？在做什麼？」，答對的重點會一格一格拼成完整的句子 | 理解並記住短文資訊 |
| 看圖說話（新） | 看圖，用說的或用注音打字。程式用關鍵字粗略判讀有沒有說到「誰、哪裡、做什麼、樣子、心情」，再問一個引導問題，最多說 3 次，最後唸示範說法 | 口語表達 |
| 因果配對（新） | 點「因為…」再點對應的「所以…」，配對成功會唸出完整句子 | 因果關係、連接詞 |

### 我的課文（所有年級，家長上傳）
課文有版權，所以**只有家長能上傳和刪除**：進入「家長區」要先答一題加法（防止小朋友自己進去），再到「課文管理」新增。小朋友在首頁「我的課文」只能玩、聽，不能改。三種做法：
1. **貼課文＋框詞（最穩）**：貼上課文，想考的詞用【】框起來，例如「小草【偷偷】地鑽出來」。按「做成關卡」，每個被框的詞變成一題三選一，錯誤選項取自課文裡其他被框的詞和程式詞庫。
2. **貼課文、不框詞**：程式只會挑出現在詞庫的動詞、形容詞，題數少，只當備案。
3. **用 Claude 拍照出題（最準）**：按「複製給 Claude 的指令」，到 Claude 貼上並附課文照片，把回傳的 JSON 貼回「匯入題目」。格式為 `{"title","text","items":[[圖示,含＿＿的句子,正確詞,錯誤詞1,錯誤詞2,提示],…]}`；`text` 是全文，用於句子排序。
每一課有三個按鈕：🧩 挖空選詞、🔢 句子排序（課文至少 3 句，隨機抽 5 句打亂，照順序一句一句點，點對會唸）、🔊 聽課文。課文最多 20 課，存在這位小朋友的瀏覽器裡。
限制：程式本身不能直接讀照片（沒有 OCR），所以拍照這步要靠 Claude；課文有版權，只放在自己家裡用，不要公開分享題庫。

### 注音拼音（只有低年級）
- 畫面上方是國字、圖和詞（例如「🌈 虹　彩虹」），點一下會唸「彩虹的虹」。
- 下面是空格：幾個注音符號就幾格，最後一格是聲調。
- 點「拼音卡」放進空格，每點一張卡就會唸出那個音；點「聲調卡」選聲調（一聲不用標，選「無」）。
- 填滿後自動檢查：不對的格子變紅、先拿掉，其他留著，再試一次。拼對會唸出完整的字和詞，並顯示標準注音。
- 點空格可以把卡片拿回去。第一次就拼對才算「學會」的進度；一輪 6 個字，拼錯的會在最後再出現一次。
- 共 42 個常見字（動物、水果、自然、身體等）。中、高年級不顯示這關。
- 限制：單一注音符號是用「同音的字」代替唸（例如 ㄅ 唸「玻」、ㄥ 唸「亨」），不是標準的符號發音；詳見第 6 節。

### 短文小偵探的規則
- **低年級（1–2）**：短文一直顯示，邊看邊答。
- **中年級（3–4）**：先讀短文，按「讀完了，開始回答」換頁，短文會藏起來，憑記憶回答。忘記了可以按「看一下原文」，系統會記次數。
- **高年級（5–6）**：玩法同中年級，但短文更長、細節更多，整輪看原文超過 2 次，星星最多 2 顆。
- **看原文的影響**（中年級）：同一題看超過 1 次，不算「學會」；整輪看超過 3 次，星星最多 2 顆。
- **數量題只問「有幾個？」**，不在題目裡寫出量詞，孩子要從短文裡找出正確的量詞（一顆、一隻、一輛…）。
- 量詞關（中年級）已加入集合量詞：一打、一堆、一對、一群、一束、一串。之後可以繼續擴充（一副、一疊、一排、一批…）。

### 多位小朋友（兄弟姐妹）
- 第一次打開會先問「誰要玩？」，輸入小名（不用真名）、選頭像和年級。
- 每位小朋友各一份存檔：星星、連續天數、學會的詞、詞卡冊、年級都分開，最多 6 位。
- 首頁最上面點名字可以換人。名字可到「家長區 > 這位小朋友」修改，也可以清除進度或刪除。
- 原本 v0.1 的存檔會自動變成第一位小朋友，不會遺失。

## 2.3b 好好說話（v0.10.0）
- 每題一個情境，三個說法講同一件事；選「對方聽起來最舒服」的。
- 答錯會顯示「為什麼這句不舒服」，答對顯示小提醒，可按「唸給我聽」把好句子唸出來。
- 建議家長請孩子「自己再說一次」，口語練習效果最好。
- 新增題目：在 `H1/H2/H3`（低／中／高）加一列 `[圖,情境,誰在說,最好說法,較差1,較差2,小提醒,為什麼1,為什麼2]`。
- 選對後可按「換我說說看」，用鍵盤上的 🎤 或注音輸入自己的說法；判定只看有沒有傷人詞（笨、討厭、走開…）與柔軟詞（請、可以嗎、謝謝、不好意思…），詞庫在程式內 `HARSH`／`SOFT`，可自行增減。
- 已知限制：最好的說法目前通常比較長、有「謝謝／不好意思」，孩子可能學到「選最長的」；題庫擴充時會刻意加入短而得體的好答案。

## 2.3c 存檔與改版不掉進度（v1.1.0）
- 進度存在瀏覽器（localStorage＋IndexedDB 雙備份）。改版不會清除；但若孩子用不同瀏覽器、無痕模式、或系統清除網站資料，進度會不見。
- 保險做法：家長區或首頁提醒的「複製存檔碼」，貼到備忘錄；之後在選人畫面按「🛟 有舊紀錄？用存檔碼找回」。
- 存檔碼以 `ZZ2:`（壓縮）開頭；舊版 JSON 備份仍可貼上還原。
- 找回是「合併」：同一位小朋友取星星較多的那份，不會把現有紀錄覆蓋掉。
- 已知限制：若分享連結在不同裝置／瀏覽器開啟，各自是獨立存檔，需用存檔碼搬移。

## 2.4 破音字與發音修正（v0.9.4）
- **批次修正**：程式內建兩套規則，不用一題一題修。
  1. `FIX`：詞語換同音字再唸，只改發音、不改畫面。例如 頭髮→頭法、生長→生掌、校長→校掌、石縫→石鳳、碰倒→碰島、一行→一航、曲調→曲掉、背著→揹著、一扇→一善、城堡→城寶、一切→一妾、蛋殼→蛋咳、朝著→招著、睡覺→睡叫。
  2. `ADV`：「慢慢地、專心地、整齊地…」這類副詞的「地」，一律改唸「的」（ㄉㄜ˙）。新增題目時，常用的副詞多半已涵蓋。
- **家長區「發音修正」**：發現某個詞唸錯，填「原詞」和「改唸成的同音字」，按「試唸」確認再按「新增」。全部小朋友通用，包含在備份裡，不用改程式。
- **檢查工具**：`tools/check_poly.js`（專案裡的 `check_poly.js`）會掃描題庫，列出還沒修正的破音字上下文，新增大量題目後執行 `node tools/check_poly.js`，人工看哪些會唸錯。
- 限制：這是用「換字」的土法，無法保證所有詞都對。正式版建議雲端台灣語音（可標拼音）或真人錄音。

## 2.3 真人注音音檔（v0.9）
- 注音關卡點拼音卡時，**有真人錄音的符號會播錄音，沒有的才退回語音合成**（唸近似的同音字）。
- 目前已有真人錄音：聲母 21 個、介音 3 個、韻母 13 個、聲調 5 個（一聲、二聲、三聲、四聲、輕聲），**全部完成**。聲調卡新增「輕聲 ˙」，點了會播你錄的聲音；輕聲標在注音符號最前面（例如 ˙ㄉㄜ），目前題庫還沒有輕聲的字，之後可加。
- **補錄的做法**：
  1. 用手機錄音，每個音之間停頓約 1.5 秒，在安靜的地方錄。
  2. 傳給 Claude，說明錄的順序，Claude 會自動切段並命名（切出的段數必須和你說的符號數相符，否則會請你重錄）。
  3. 或自己切：每個音存成 mp3，檔名就是符號，例如 `ㄐ.mp3`，放進 `audio/` 資料夾，聲調檔名用 `一聲.mp3`～`四聲.mp3`、`輕聲.mp3`。
  4. 在 `zizi.html` 同一層執行 `python3 build_audio.py`，音檔會被嵌進 `zizi.html`（不需要另外放檔案）。
- `build_audio.py` 在專案資料夾。目前 42 個音檔嵌入後 `zizi.html` 約 400 KB。
- 錄音切點用音量偵測：每個音前後會多留一點點空白並淡入淡出，避免爆音。

## 2.1 遊戲外觀（v0.7）
- 首頁精簡成「夥伴＋今日任務＋關卡磚」：夥伴會上下晃動，每個關卡是大圖示的立體磚塊，左上角是今天的進度（今天 1/3 → ✓ 今天完成），說明文字改成越少越好。
- 作答時：三個選項各有顏色、按下去有立體下壓感；答對有星星飛散、連對 3 題以上會跳出「連對 N！🔥」並且音調越來越高；答錯手機會輕震動（聲音開著時）。
- 過關畫面有大型彩帶特效。畫面切換有淡入動畫。
- 系統若開了「減少動態效果」，動畫和特效會自動關閉。
- 320px 窄螢幕（舊款 iPhone SE）已於 v0.9.8 修正，首頁與各關卡不再橫向捲動。

## 3. 每日任務與星星（v0.6 改版）
- **每個關卡每天答 3 題就算完成**，首頁「今日任務」一排圖示會顯示 0/3、1/3、✓，點圖示直接進該關。目的：不讓孩子只玩喜歡的關卡。
- **星星**：每個關卡每天只有第一輪會給星星（1–3 顆，看第一次答對的比例）。同一關當天再玩，不再加星星，但答題都會存進學習紀錄，也會累積「學會」進度。
- **全部關卡都完成**：當天再加 3 顆星（只領一次）。「我的課文」不算在每日任務裡。
- **夥伴吃蘋果**：同一題連續答對 2 次，夥伴吃到 1 顆蘋果；吃滿就長大。點夥伴那一區會唸出說明。
- **學習紀錄**：家長區「學習紀錄（近 14 天）」表格，每天每個關卡答了幾題，達標的格子變綠；上方顯示累積練習天數、答題數、學會的詞數。「產生回報」也會附近 7 天答題數。

## 5. 第一次設定與分享給其他裝置
- 不用安裝。發佈後是一個網頁連結，任何手機、平板、電腦的瀏覽器都能開。
- **公開給測試的人**：我無法替你設定分享，請你自己做：開啟頁面 → 右上角「分享」→ 把權限設成「知道連結的人都能檢視」（實際選項名稱依你的方案而定，若找不到公開選項，可能是組織設定限制）。設定好後，把網址傳給測試的家長即可。
- 測試的人不需要任何帳號就能玩（看圖說話已改成不用 AI）。
- 若你的方案不能公開連結，替代做法：把 `zizi.html` 放到任何能放靜態網頁的地方（例如 GitHub Pages、Netlify Drop），就會得到一個公開網址。
- 每個人的進度只存在自己的瀏覽器，不會互相影響；記得用家長區的「備份」保存。

### 看圖說話怎麼判讀
- 全部在手機本機完成，不需要登入任何帳號，也不會送出孩子說的話。
- 第一關先看「是不是一句話」：只丟名詞（例如「腳踏車 弟弟 太陽」）不算，程式會先肯定孩子看到的東西，再引導他說成「誰＋在哪裡＋做什麼」。
- 第二關才比對「誰、哪裡、做什麼、樣子、心情」（高年級再加「原因」，要有「因為／為了／由於」等說法），其中「做什麼」「樣子」只收動詞和形容詞，不收名詞。
- 方法是關鍵字比對，說法和關鍵字不同時可能判錯，所以建議家長在旁邊聽，用畫面上的引導問題帶孩子多說一點。
- 之後如果要升級成更準的 AI 判讀，必須在自己的伺服器上做（見第 10 節）。

## 6. 朗讀（台灣腔、破音字）
- **只會用「中文（台灣）」聲音**；裝置上沒有的話寧可不選，也不退用大陸（zh-CN）聲音，避免大陸腔。家長區會標示 ✓台灣／✗非台灣腔，並顯示下載步驟。
- 程式會優先選裝置上的「中文（台灣）」聲音，例如 iPhone 的 Mei-Jia（美佳）。家長區可以手動換聲音。
- 常見破音字用「換同音字」的方式處理，只影響發音、不影響畫面。目前處理：朝著（ㄓㄠ）、長著（ㄓㄤˇ）、睡覺（ㄐㄧㄠˋ）、慢慢地／開心地（ㄉㄜ˙）等。清單在程式的 `FIX` 區，發現唸錯的詞可以往裡面加。
- 手機要有「中文（台灣）」聲音：iPhone 到「設定 > 輔助使用 > 語音內容 > 聲音 > 中文」下載；Android 到「設定 > 一般管理 > 文字轉語音」。
- **注音卡的聲音**：程式用一個同音的字來唸每個注音符號（清單在程式的 `ZSAY`，例如 ㄅ→玻、ㄆ→坡、ㄩ→迂），聲調卡唸「媽、麻、馬、罵」。這是近似，ㄝ、ㄥ、ㄦ 等較不準；孩子正式學注音時，建議改用真人錄音。
- 限制：瀏覽器內建語音無法保證每個破音字都對。正式版建議改用雲端台灣中文語音（可用拼音標註破音字）或真人錄音。

## 7. 看圖說話怎麼「開口」
網頁無法直接用麥克風錄音，所以用最簡單的方式：
1. 點「🎤 開始說話」，輸入格會跳出手機鍵盤。
2. 按鍵盤上的 🎤 聽寫鍵，孩子直接說話，文字會自己打進格子。
3. 也可以直接用注音打字，順便練習ㄅㄆㄇ拼音。
4. 正式 App 版可以直接錄音並辨識，到時不需要這個步驟。

## 8. 如何新增題目
打開 `zizi.html`，找到題庫區（我的課文題目不用改程式，直接在 App 裡新增；`ZY`（注音）、`Q1 Q2 Q3 V1 V2 V3 A1 A2 A3 M1 M2 M3 E1 E2 E3 TS`）。
- 選擇題：`[圖示, 句子（空格用＿＿）, 正確答案, 干擾1, 干擾2, 小提醒]`
- 注音拼音：`[圖示, 字, 詞, [注音符號…], 聲調 1–4]`，例如 `['🍎','果','蘋果',['ㄍ','ㄨ','ㄛ'],3]`；挑不容易有破音的字
- 因果配對：`[圖示, 因為…, 所以…]`，同一年級的組別之間不要有兩個都說得通
- 擴句：`{e, noun, scene, parts:[[標籤,位置,問題,答案,干擾1,干擾2],…]}`，位置 `b`＝主角前面、`a`＝主角後面
- 看圖說話（高年級多一項「原因」，要說出「因為…」）：`{lv, pic, title, cap, desc, model, kw}`；`kw` 是小幫手比對用的關鍵字（誰、哪裡、做什麼、樣子各一組），`desc` 是圖片的標準內容，之後接 AI 時才用得到

## 9. 疑難排解
| 狀況 | 處理 |
|---|---|
| 沒有聲音 | 右上角鈴鐺是否被關閉；手機是否靜音 |
| 沒有朗讀 | 裝置沒有中文語音，見第 6 節下載 |
| 朗讀不是台灣腔 | 家長區 > 朗讀聲音，換成標示 zh-TW 的聲音 |
| 某個詞唸錯 | 把該詞加進程式 `FIX` 清單，用同音字替代 |
| 鍵盤上找不到 🎤 | 到手機「設定 > 一般 > 鍵盤」開啟「聽寫」（iPhone），或改用注音打字 |
| 看圖說話判得不準 | 正常，這是關鍵字粗判；請家長在旁協助，或回報說法讓關鍵字清單補充 |
| 進度不見 | 換裝置、清除瀏覽器資料、無痕視窗都會清空 |
| 手機上畫面左右能拖動 | 回報給 Stacy，附上手機型號 |
