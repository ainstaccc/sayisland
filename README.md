### 成語、換句話說、造句（中、高年級，v1.21.0；v1.22.0 改版）
- 這三關**只有中、高年級才有**，低年級看不到（低年級有注音三關）。因為首頁「今日任務」是「每個關卡每天 3 題」，中、高年級的今日任務會從 9 關變成 12 關，全部完成才算（第 3 節）。
- **成語、換句話說**：就是一般的三選一選擇題（資料格式同選擇題，見第 8 節），空格要填的是成語或近義詞。選項一律排成一欄，4 個字也不會被切掉。成語題的小提醒以成語開頭，後面解釋意思，答對、答錯後都會看到。已學會的成語、近義詞會收進「我的詞卡冊」。
- **造句**（一輪 5 題）：
  - 中年級「詞塊排句子」：詞塊是依詞組切好的（例：小明／在公園／放風箏），點一下放進上面的格子，點格子裡的詞塊可以拿下來重排；排滿自動檢查。有些句子的詞塊可以換位置（例：「早上」放前面或放主詞後面都對），這種題已經另外登記了「其他可接受的排法」。錯 3 次會出現「看答案」。
  - 中年級「對稱句」：前半句固定，選出和它「句型一樣」的後半句（例：山上有樹，山下＿＿→有河）。**三個選項字數一定一樣，而且都能讀得通，只有一個和前半句的詞性、結構相同**，所以不能用字數猜答案。答錯只提示「句型（詞性、結構）要一樣」，不會講出答案；答對才顯示完整說明。
  - 中年級「照樣造句」：畫面顯示句型（例：因為…所以…）、一句話提示和一個範例，孩子寫自己的句子。程式檢查有沒有依序用到句型的字、夠不夠長、有沒有照抄範例。
  - 高年級「改寫句子」：畫面顯示原句和改寫指示。程式檢查：①有沒有保留原句的重點字詞 ②有沒有符合指示（雙重否定＝句中至少兩個否定字「不、沒、無、非」；反問＝有問號或「難道、豈、哪裡」等；被／把字句＝有那個字；轉述＝沒有引號和冒號；比喻＝有「像、彷彿、好像…」；換詞＝沒用到禁用的詞；縮短＝不超過字數上限）③夠不夠長（或不超過字數上限）④沒有照抄原句（改寫題看不到參考改寫，所以答案剛好等於參考改寫也算對）；連錯 3 次才出現「看參考改寫」，看了不給星星。
  - 高年級「自己造句」（以及上面的照樣造句、改寫句子，原理相同）：程式**只檢查三件事**：①有沒有用到指定的詞語（關聯詞可接受常見的替代說法，例如「不但…還…」「雖然…可是…」也算）②句子夠不夠長（每題有最少字數，通常 8 個字）③句尾有沒有標點（只提醒，不擋）。另外會擋掉「直接抄參考句子」。通過後才顯示參考造句，並把孩子的句子收進「我的句子」。**程式不會判斷句子通不通順、意思合不合理**（例如只寫「果然，今天很開心。」也會過），所以請家長在旁邊聽孩子念自己的句子。沒通過最多改兩次，之後可看參考造句（這題不算第一次就答對）。
- 判斷用的規則和資料都在程式裡的「造句」區塊（搜尋 `startSJ`、`sjJudge`）；新增題目的格式見第 8 節。

### 注音拼音（只有低年級）
- 畫面上方是國字、圖和詞（例如「🌈 虹　彩虹」），點一下會唸「彩虹的虹」。
- 下面是空格：幾個注音符號就幾格，最後一格是聲調。
- 點「拼音卡」放進空格，每點一張卡就會唸出那個音；點「聲調卡」選聲調（一聲不用標，選「無」）。
- 填滿後自動檢查：不對的格子變紅、先拿掉，其他留著，再試一次。拼對會唸出完整的字和詞，並顯示標準注音。
- 點空格可以把卡片拿回去。第一次就拼對才算「學會」的進度；一輪 6 個字，拼錯的會在最後再出現一次。
- **拼音卡怎麼配（v1.19.2）**：固定 6 張卡，每個正確的音旁邊一定放「最容易跟它搞混的音」，而且**兩兩相鄰**（孩子一眼就是在「二選一」辨音）。例：答案有ㄣ → 旁邊放ㄥ；ㄔ → ㄘ；ㄛ → ㄡ；ㄓ → ㄗ；ㄢ → ㄤ。只有一個音的字（如「日」ㄖ）會把 3 個易混音一起放（ㄖ／ㄕ／ㄌ／ㄦ，排第一排）。卡片還有空位時，補上孩子最常錯的成對（ㄣㄥ、ㄢㄤ、ㄔㄘ、ㄓㄗ、ㄛㄡ、ㄕㄙ…）。
  - 混淆表在程式的 `ZC`（每個符號 → 容易混的音，越前面越常錯）；補位成對在 `ZFOCUS`。想調整只改這兩張表。
  - 混淆依據：送氣／不送氣（ㄅㄆ、ㄉㄊ、ㄍㄎ、ㄐㄑ、ㄓㄔ、ㄗㄘ）、翹舌／平舌（ㄓㄗ、ㄔㄘ、ㄕㄙ）、前後鼻音（ㄣㄥ、ㄢㄤ）、字形相近（ㄅㄉ、ㄇㄋ、ㄣㄥ）、台灣腔常混（ㄋㄌ、ㄖㄌ、ㄈㄏ）、韻母相近（ㄛㄡ、ㄜㄛ、ㄞㄟ、ㄠㄡ、ㄧㄩㄨ）。這是依常見教學經驗整理，不是官方標準，覺得不準可以直接改表。
- 共 42 個常見字（動物、水果、自然、身體等）。中、高年級不顯示這關。
- 限制：單一注音符號是用「同音的字」代替唸（例如 ㄅ 唸「玻」、ㄥ 唸「亨」），不是標準的符號發音；詳見第 6 節。

### 短文小偵探的規則
- **低年級（1–2）**：短文一直顯示，邊看邊答。
- **中年級（3–4）**：先讀短文，按「讀完了，開始回答」換頁，短文會藏起來，憑記憶回答。忘記了可以按「看一下原文」，系統會記次數。
- **高年級（5–6）**：玩法同中年級，但短文更長、細節更多，整輪看原文超過 2 次，星星最多 2 顆。
- **看原文的影響**（中年級）：同一題看超過 1 次，不算「學會」；整輪看超過 3 次，星星最多 2 顆。
- **數量題只問「有幾個？」**，不在題目裡寫出量詞，孩子要從短文裡找出正確的量詞（一顆、一隻、一輛…）。
- 量詞關（中年級）已加入集合量詞：一打、一堆、一對、一群、一束、一串。之後可以繼續擴充（一副、一疊、一排、一批…）。

- **語音稽核**：`node tools/voice_audit.js --lv=1,2,3` 走遍所有關卡、按所有「唸」按鈕，列出掉到機器人的句子；要印 `VOICE AUDIT: ALL PRERECORDED`。

- **產音檔**：`node tools/tts/build_manifest.js`（盤點全部會唸的句子，寫 `tools/tts/items.json`）→ `python3 tools/tts/gen_audio.py`（只補沒有的）→ `node tools/tts/build_manifest.js --check`（要顯示「manifest 一致」）。雲端可執行（claude.ai 已允許 `speech.platform.bing.com`），細節看 `tools/tts/README.md`。**每晚 05:12（台北）排程「說說島每晚補預錄音檔」**照 `tools/TTS_NIGHTLY.md` 自動補新題目的音檔、並在發音修正（`FIX`）讓唸法改變時重產該句（`tools/tts/speak-log.json` 記錄每個檔當時合成的字）。停止排程：到 Claude 排程清單把它停用。
- 「聲音試聽」關已於 v1.22.5 移除（已全面換新語音），對應 20 個孤兒 mp3 一併刪除。
- **首頁小豬／提示文字（v1.22.5）**：點小豬唸的是 `heroParts()` 拆出的固定句（不含孩子名字、進度分數），共 324 句全部預錄（hero 類）；用 `sayList()` 依序播放，缺檔才退回手機語音。新增寵物或改 `PAT` 後要重跑 build_manifest → gen_audio。
- 預錄音檔不經過手機語音的 `FIX` 修正以外的處理：唸錯的詞要先改 `FIX`，再 `gen_audio.py --force --only <關卡代號>` 重產。

## 2.4 破音字與發音修正（v0.9.4）
- **批次修正**：程式內建兩套規則，不用一題一題修。
  1. `FIX`：詞語換同音字再唸，只改發音、不改畫面。例如 頭髮→頭法、生長→生掌、校長→校掌、石縫→石鳳、碰倒→碰島、一行→一航、曲調→曲掉、背著→揹著、一扇→一善、城堡→城寶、一切→一妾、蛋殼→蛋咳、朝著→招著、睡覺→睡叫。
  2. `ADV`：「慢慢地、專心地、整齊地…」這類副詞的「地」，一律改唸「的」（ㄉㄜ˙）。新增題目時，常用的副詞多半已涵蓋。
- **家長區「發音修正」**：發現某個詞唸錯，填「原詞」和「改唸成的同音字」，按「試唸」確認再按「新增」。全部小朋友通用，包含在備份裡，不用改程式。
- **檢查工具**：`node tools/check_poly.js`（在 repo 根目錄）。會掃 `index.html` 內建題庫**加上 `bank.js`（每晚新增的題）**，列出還沒有發音修正的破音字上下文。已在 `FIX` 詞裡的、或記在 `tools/pron-ok.txt`（已確認唸得對）的詞會自動跳過。參數：`--json`（給排程讀）、`--bank-only`（只看夜間新增）、`--limit=N`。家長區「發音修正」存在各人手機裡，這支工具看不到。
- **每晚修發音排程（2026-11-07 起）**：排程「說說島每晚修發音」每天凌晨 04:21（台北）照 `tools/PRON_NIGHTLY.md` 執行：掃出最多 60 筆 → 查教育部辭典確認 → 只修確定唸錯的（加進 `FIX`）→ 沒問題的記進 `pron-ok.txt` → 驗證通過才 push；不確定的列「待人工確認」回報給 Stacy，不自己猜。每晚紀錄在 `tools/pron-log.md`。停止排程：到 Claude 的排程清單把「說說島每晚修發音」停用。
- **範圍**：這個排程只修「手機語音」的發音（`FIX`）。預錄音檔（微軟台灣語音）要在 Stacy 電腦上產，雲端連不到微軟語音服務，所以不在排程內。
- 限制：這是用「換字」的土法，無法保證所有詞都對。正式版建議雲端台灣語音（可標拼音）或真人錄音。

## 2.3 真人注音音檔（v0.9）
- 注音關卡點拼音卡時，**有真人錄音的符號會播錄音，沒有的才退回語音合成**（唸近似的同音字）。
- 目前已有真人錄音：聲母 21 個、介音 3 個、韻母 13 個、聲調 5 個（一聲、二聲、三聲、四聲、輕聲），**全部完成**。聲調卡新增「輕聲 ˙」，點了會播你錄的聲音；輕聲標在注音符號最前面（例如 ˙ㄉㄜ），目前題庫還沒有輕聲的字，之後可加。
- **補錄的做法**：
  1. 用手機錄音，每個音之間停頓約 1.5 秒，在安靜的地方錄。
  2. 傳給 Claude，說明錄的順序，Claude 會自動切段並命名（切出的段數必須和你說的符號數相符，否則會請你重錄）。
  3. 或自己切：每個音存成 mp3，檔名就是符號，例如 `ㄐ.mp3`，放進 `audio/` 資料夾，聲調檔名用 `一聲.mp3`～`四聲.mp3`、`輕聲.mp3`。
  4. 在 `zizi.html` 同一層執行 `python3 build_audio.py`，音檔會被嵌進 `zizi.html`（不需要另外放檔案）。
- `build_audio.py` 在專案資料夾。目前 42 個音檔嵌入後 `zizi.html` 約 400 KB。
- 錄音切點用音量偵測：每個音前後會多留一點點空白並淡入淡出，避免爆音。

## 5. 第一次設定與分享給其他裝置

### 看圖說話怎麼判讀
- 全部在手機本機完成，不需要登入任何帳號，也不會送出孩子說的話。
- 第一關先看「是不是一句話」：只丟名詞（例如「腳踏車 弟弟 太陽」）不算，程式會先肯定孩子看到的東西，再引導他說成「誰＋在哪裡＋做什麼」。
- 第二關才比對「誰、哪裡、做什麼、樣子、心情」（高年級再加「原因」，要有「因為／為了／由於」等說法），其中「做什麼」「樣子」只收動詞和形容詞，不收名詞。
- 方法是關鍵字比對，說法和關鍵字不同時可能判錯，所以建議家長在旁邊聽，用畫面上的引導問題帶孩子多說一點。
- 之後如果要升級成更準的 AI 判讀，必須在自己的伺服器上做（見第 10 節）。

## 6. 朗讀（台灣腔、破音字）
- **只會用「中文（台灣）」聲音**；裝置上沒有的話寧可不選，也不退用大陸（zh-CN）聲音，避免大陸腔。家長區會標示 ✓台灣／✗非台灣腔，並顯示下載步驟。
- 程式會優先選裝置上的「中文（台灣）」聲音，例如 iPhone 的 Mei-Jia（美佳）。家長區可以手動換聲音。
- 常見破音字用「換同音字」的方式處理，只影響發音、不影響畫面。目前處理：朝著（ㄓㄠ）、長著（ㄓㄤˇ）、睡覺（ㄐㄧㄠˋ）、慢慢地／開心地（ㄉㄜ˙）等。清單在程式的 `FIX` 區，發現唸錯的詞可以往裡面加。
- 手機要有「中文（台灣）」聲音：iPhone 到「設定 > 輔助使用 > 語音內容 > 聲音 > 中文」下載；Android 到「設定 > 一般管理 > 文字轉語音」。
- **注音卡的聲音**：程式用一個同音的字來唸每個注音符號（清單在程式的 `ZSAY`，例如 ㄅ→玻、ㄆ→坡、ㄩ→迂），聲調卡唸「媽、麻、馬、罵」。這是近似，ㄝ、ㄥ、ㄦ 等較不準；孩子正式學注音時，建議改用真人錄音。
- 限制：瀏覽器內建語音無法保證每個破音字都對。正式版建議改用雲端台灣中文語音（可用拼音標註破音字）或真人錄音。

## 7. 看圖說話怎麼「開口」
網頁無法直接用麥克風錄音，所以用最簡單的方式：
1. 點「🎤 開始說話」，輸入格會跳出手機鍵盤。
2. 按鍵盤上的 🎤 聽寫鍵，孩子直接說話，文字會自己打進格子。
3. 也可以直接用注音打字，順便練習ㄅㄆㄇ拼音。
4. 正式 App 版可以直接錄音並辨識，到時不需要這個步驟。

## 8. 如何新增題目
打開 `zizi.html`，找到題庫區（`ZY`（注音）、`Q1 Q2 Q3 V1 V2 V3 A1 A2 A3 M1 M2 M3 E1 E2 E3 TS`）。
- 選擇題：`[圖示, 句子（空格用＿＿）, 正確答案, 干擾1, 干擾2, 小提醒]`
- 注音拼音：`[圖示, 字, 詞, [注音符號…], 聲調 1–4]`，例如 `['🍎','果','蘋果',['ㄍ','ㄨ','ㄛ'],3]`；挑不容易有破音的字
- 量詞、動詞、形容詞（`Q1–Q3`、`V1–V3`、`A1–A3`）格式不變；填入玩法只用「正確答案」，干擾字不會顯示（三選一格式仍保留，其他關卡如部首小幫手、選對字、注音辨辨看、好好說話仍用三選一）。同一組 4 題如果有兩題都說得通同一個字，請避免放在同年級一起出現。
- 注音辨辨看（程式裡的 `ZB`）：`[圖示, 詞, 字, 正確注音, 干擾1, 干擾2, 類型]`，類型 `n`＝ㄣ、`g`＝ㄥ、`a`＝ㄢ、`h`＝ㄤ、`c`＝ㄔ、`z`＝ㄘ、`cz`＝ㄓ或ㄗ（決定答對後顯示的小提醒）。三個選項的聲調要一樣，只改要分辨的那個音；字請挑沒有破音的。注音務必對照教育部《國語辭典》；每晚自動出題目前不會加這一關。
- 部首小幫手（`R1 R2 R3`）、選對字（`Y1 Y2 Y3`）：格式同選擇題 `[圖示, 句子（空格用＿＿）, 正確答案, 干擾1, 干擾2, 小提醒]`。部首題的答案請照教育部《國語辭典》的部首；選對字的干擾字要是真的容易混淆的字，且整句只能有一個說得通。這兩關刻意不顯示注音，避免寫錯；要加注音前，請先對照教育部資料。
- 成語（`CY2 CY3`）、換句話說（`PW2 PW3`）：格式同選擇題 `[圖示, 句子（空格用＿＿）, 正確答案, 干擾1, 干擾2, 小提醒]`，2＝中年級、3＝高年級（沒有低年級）。選項 ≤4 個字；題目 ≤40 字；成語題的小提醒要以成語開頭再解釋意思（例：`一心一意：心思都放在同一件事上，很專心。`）。**成語題的句子不能直接講出成語的解釋**（否則一看就猜到）；干擾項要是意思相近、孩子可能混淆的成語，但依句子情境只有一個最合適；**每個年級情緒類成語要占一半以上**，題庫新增時也要維持（見 `tools/NIGHTLY.md`）。圖示只是答完才出現的獎勵，不是線索。
- 造句（`SJ2`＝中年級、`SJ3`＝高年級），每列第一個欄位是類型：
  - 排句子（`SJ2`）：`['o', 圖, [詞塊…], 正解句(含標點), [其他可接受的句子…]]`，詞塊 3～6 個，**依序拼起來要等於正解句**（標點除外）；詞塊要依詞組切（例：`['小明','在公園','放風箏']`）。
  - 對稱句（`SJ2`）：`['s', 圖, 含＿＿的句子, 正解, 干擾1, 干擾2, 小提醒]`；**三個選項字數必須一樣**（驗證工具會擋），干擾項要是「讀得通、但句型和前半句不同」的詞句，且只有正解和前半句詞性、結構一樣。
  - 自己造句（`SJ3`）：`['w', 圖, 詞語, 提示, [必須依序出現的字串…], 最少字數, 參考造句]`；必須出現的字串可以用 `|` 列出替代說法（例：`'而且|還|也|更'`）；參考造句必須通過自己的檢查（依序用到詞語、不少於最少字數、有句尾標點）。
  - 照樣造句（`SJ2`）：`['x', 圖, 句型, 提示, [必須依序出現的字串…], 最少字數, 參考造句, 範例句]`；範例句和參考造句都要通過檢查，且不能相同。
  - 改寫句子（`SJ3`）：`['r', 圖, 原句, 改寫指示, [必須保留的字串…(可用|)], 規則, 最少字數, 參考改寫, [禁用的詞…], 最多字數(0＝不限)]`；規則可填 `'#neg2'`（雙重否定）、`'#q'`（反問）、`'#noquote'`（轉述，無引號冒號）、必含字串如 `'被'`、`'像|彷彿|如同'`，或空字串。
  - 這三關用 `node tools/add.js`、`node tools/check.js` 驗證（規則在 `tools/lib-new.js`）。**排程的每晚擴充目前還沒有納入這三關**，需要時要改 `tools/NIGHTLY.md` 的清單。
- 因果配對：`[圖示, 因為…, 所以…]`，同一年級的組別之間不要有兩個都說得通
- 擴句：`{e, noun, scene, parts:[[標籤,位置,問題,答案,干擾1,干擾2],…]}`，位置 `b`＝主角前面、`a`＝主角後面
- 看圖說話（高年級多一項「原因」，要說出「因為…」）：`{lv, pic, title, cap, desc, model, kw}`；`kw` 是小幫手比對用的關鍵字（誰、哪裡、做什麼、樣子各一組），`desc` 是圖片的標準內容，之後接 AI 時才用得到

## 9. 疑難排解

- **回饋框（答對／再想一想）字變很小、跑出框外**：是 CSS class 名稱撞名（填入玩法的空格誤用了回饋框的 `.fb`，v1.18.0 已改成 `.fbk`）。新增樣式前先 `grep` 確認 class 沒被用過（已用過：`.mgrid` `.fb` `.zq`）。
- **直式注音（v1.18.0 起，所有注音都是直式）**：符號由上往下排；ˊ ˇ ˋ 放在整組符號的右側正中間（v1.18.5 起；v1.18.4 以前是最後一個符號右上角）；一聲不標；輕聲˙放在第一個符號上方。程式裡 `zyV()` 負責轉換，樣式在 `.zv`。
